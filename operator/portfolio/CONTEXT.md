# Case studies and portfolio — O2

O2 produces a case study per finished build and a current portfolio index so that every proposal cites real work and every training example is true.

## Inputs

- `clients/<slug>/handover/pack.md` and the client's approval (by email, outside git).

## Process

- Defined when the module is built (Wave 1 for C1, C2, D2, D4; later waves for the rest).
- Start cold from this folder. Read only what Inputs names.

## Outputs

- `cases/<slug>.md` · `index.md`. The public subset feeds `content/` and the business site.

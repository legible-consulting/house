# Codex Remote

OpenAI Codex's remote route: a Codex session started on the desktop app and steered from the
mobile app on the same account and workspace. The course gives it as the parallel to Claude
Code's remote session.

## Verdict: decline

Decline (why: house already steers sessions from the phone through Claude Code on the web and
the Claude app, against the `legible` cloud environment, with no home host to keep awake;
Codex Remote would add a second vendor account and a second agent that reads none of the
`.claude/` hooks the house rules depend on · 2026-10-16).

## What would change it

- A client whose repo or team runs on Codex, so D1–D4 work has to happen in their tool.
- Claude Code losing remote or cloud sessions, or the phone route failing the lesson's
  marker-file and reconnect checks while Codex passes them.

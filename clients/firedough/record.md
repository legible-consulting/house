# Firedough Pizza

Firedough Pizza is a wood-fired pizza truck around Strandhill, Co. Sligo, on Ireland's Wild
Atlantic Way. The site is one landing page, a Next.js build in `k0d0minio/firedough`, first
made in v0.app and still synced from it. The page still carries v0 defaults and placeholder
contact details. The repo is still in the legacy lane (`~/Desktop/Apps/projects/firedough`).
The build is active. Jamie does it for free: he considers the client close family or a friend.
There is no price, no quote and no agreement (Jamie, 2026-11-09). The folder was opened on
2026-11-09 for a build that started before the house existed.

# Git for Global Law

The law of many countries as one git history: each country's law is a submodule, and each commit is one law that takes effect. It ships a read-only MCP server with 18 tools that read a provision on a date. Licence CC0 for the repository; the law text carries each corpus's own terms.

## Verdict: decline

Decline: no line in `core/services.md` sells legal research, no client is in law, and the README names no Portuguese corpus; a legal-domain client who asks for grounded retrieval over law would reopen it under AI business infrastructure.

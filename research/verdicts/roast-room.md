# Roast Room

A Claude Code skill by Nate Herk. A chair agent asks about a business decision, then a council of sub-agents, each a persona of a real business figure (Bezos, Paul Graham, Hormozi, Buffett and others) built from public work, argue it, vote and write a scored verdict and a PDF. A small local web app plays the session back. Licence MIT; it needs Claude Code and Node 20.

## Verdict: decline

Decline (why: the Workshop line (`core/services.md`) teaches folders as the architecture and a human gate at every boundary, and a council of agents that votes on a decision teaches the opposite; the AI consultancy line sells Jamie's own second opinion, which a panel of celebrity personas does not replace; for the workshop's one multi-agent example the house already watches Hermes Agent and OpenCode · 2026-10-30).

## What would change it

- A workshop group that asks to see sub-agents work in parallel: then a session as a live demo, framed as what not to hand a decision to.

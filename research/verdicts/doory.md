# Doory

Doory is an open-source design editor in the browser, offered as a Canva alternative: posters, social posts, slides, resumes and cards, with export to PNG, JPG, SVG, PDF, MP4 and GIF. Siam (shaongitbd) makes it. It has no paid plan, and you self-host it with Docker (Django and Postgres) or nginx. The README calls it young: ten starter templates. Licence: Attribution Assurance License.

## Verdict: decline

Decline (why: the house runs no server of its own, only Vercel and the cloud environment in `core/stack.md`, and a Django and Postgres app to keep alive for a few social images costs more than it saves; the licence also asks for visible credit to the author; brand and graphic design are in a build only when a proposal names them, `core/services.md` · 2026-10-27).

## What would change it

- A client build that needs a design editor inside the client's own product, under a licence the client accepts.
- A hosted Doory that needs no server from the house.

# Ever Gauzy

Ever Gauzy is an open-source business management platform from Ever Co: ERP, CRM, HR, applicant tracking, project management, time tracking, invoicing and sales pipeline in one app. It runs as a server, a web app and a desktop app. The default licence is the "Ever Gauzy Platform Community Edition"; Small Business and Enterprise licences are paid. The README asks the operator to set four strong secrets before the API starts.

## Verdict: decline

Decline (why: the house sells custom builds (`core/services.md`, App and Platform), not the hosting of a large third-party ERP; to run Gauzy for a client is a retainer of upgrades, secrets and database care for code the house did not write, and the house's own records already live in the desk and the folders · 2026-10-26).

## What would change it

- A client needs CRM, HR and time tracking together, and a build of the same scope costs more than a hosted Gauzy and its retainer. Then a proposal names it as the smallest honest version.

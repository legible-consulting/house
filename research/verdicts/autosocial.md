# AutoSocial Studio

A local dashboard that queues and posts short videos to TikTok, Instagram and YouTube for several accounts. It drives the upload pages with Playwright and keeps each account's browser session on the machine. It also downloads reference clips with yt-dlp and alters videos with FFmpeg so that each copy looks unique. Windows first, Node.js 18+. Licence MIT. No release; last push 2026-06-10.

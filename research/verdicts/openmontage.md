# OpenMontage

OpenMontage turns a coding agent such as Claude Code into a video production pipeline: research, script, generated assets, edit and render (Remotion, FFmpeg, HyperFrames). It ships pipeline definitions and Python tools, and it can start from a reference video. The tool is free; the generated clips, voices and music cost money per video at the providers (the README shows $1 to $5 a film). Licence AGPLv3.

## Verdict: watch

Watch (why: the house sells no video line in `core/services.md`, and each render spends money at third-party providers, which waits for Jamie; but a short explainer for a case study or a workshop is a plausible content need, and the pipeline runs inside the Claude Code sessions the house already uses · 2026-10-27).

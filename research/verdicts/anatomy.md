# Anatomy

Anatomy is an agent skill that explains a technical idea as an interactive isometric drawing of an invented machine, as a standalone HTML or SVG page. It uses only Node's built-in modules. Licence MIT.

## Verdict: watch

Watch (why: the workshop teaches ICM and proposals explain builds (`core/services.md`), and the build and Graphviz are adopted for diagrams (`verdicts/d2.md`, `verdicts/graphviz.md`); a figure that moves could make one ICM idea stick in a workshop, but it is one figure per prompt, not a diagram source in git · 2026-10-25).

## What would change it

- One Anatomy figure of a stage folder and its contract works in a workshop.
- A proposal needs an interactive explainer a client opens on the phone.

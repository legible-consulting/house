# Client research — S2

S2 produces a prospect profile and an industry primer so that Jamie enters the first call knowing the client's trade and the proposal speaks their language.

## Inputs

- `clients/<slug>/record.md`.
- `operator/research/primers/` if a primer for the trade exists.
- `legible-consulting/library` only when a contract line here names a path in it.

## Process

- Defined when the module is built (Wave 1 for C1, C2, D2, D4; later waves for the rest).
- Start cold from this folder. Read only what Inputs names.

## Outputs

- `clients/<slug>/research/profile.md` · `clients/<slug>/research/primer.md` (a new primer is also copied to `operator/research/primers/`).

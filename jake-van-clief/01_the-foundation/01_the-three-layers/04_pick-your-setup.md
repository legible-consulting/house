# 1.4 Pick Your Setup

*The Foundation › Module 1: The Three Layers · Author: Jake Van Clief · Source: Skool video + text page · Length: ~3:30 (estimated from captions)*

## Summary

A decision lesson closing module one. Any AI setup has four pieces: the model, the harness, the interface and where it runs. Most choices are fine and folders travel between them, so the useful skill is knowing which piece a switch would change and counting the full cost, not just the subscription. A one-file summary test proves whichever setup you choose.

## Core concepts

- **Four pieces:** model (brain), harness (the app giving file and run access), interface (chat, terminal, editor) and runtime location (cloud, local, mixed).
- **Two separate local choices:** keeping files local is independent of running the model locally; a local model buys privacy and offline use at a cost in quality and hardware.
- **Whole cost:** subscription plus setup, upkeep, checking output and waiting; a cheap tool that consumes a weekend is not cheap.
- **Custom earns its place** only when no app does the job or at a scale apps cannot handle.

## Frameworks and methods

Pick by need: newcomers use the Claude app; people who live in code use Claude Code or Codex in the editor; Microsoft or Google shops check what is already included; privacy-driven setups use a local model.

The tiny test: give it a folder with one file, ask for a one-page summary saved next to it, then open the result yourself outside the AI.

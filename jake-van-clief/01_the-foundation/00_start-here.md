# Start Here

*The Foundation · Author: Jake Van Clief · Source: Skool video + text page · Length: ~3:30 (estimated from captions)*

## Summary

The course map. Foundations teaches people to stop treating AI as a smart search bar and instead run it inside their own files, so that one short sentence kicks off real work whose every part can be opened and inspected. Jake frames everything around three layers (chat, skills, folders with one agent), lays out three modules, and tells learners where to enter depending on what they already do. The page adds dated setup details and the two side sections.

## Core concepts

- **Three layers:** a way of organising and reusing work, not a skill ladder; layer 3 has no ceiling.
- **Simple, complex, simple again:** build the intricate machinery underneath, then fold it back into a one-line request with the work visible below.
- **Plain English in text files:** the pitch is that almost nothing requires coding.
- **Self-demonstrating:** he says the video's script and animation came out of a single folder, which the course later opens up.
- **Dated details:** apps change every couple of weeks, so each lesson page carries current setup steps with a date instead of re-recording.

## Frameworks and methods

1. Module 1: one hands-on lesson per layer, then picking a setup.
2. Module 2: outcome first, folder design, then giving one folder different jobs.
3. Module 3: stages you can step into, code for the steady parts, keeping it useful and handing it on.

Entry points: new to AI beyond questions starts at 1.1; Projects or saved prompts users start at 1.2; folder users with Claude Code or Codex start at 1.3 or module 2.

## Apply to icm-workshop

- **O4 workshop kit:** adopt the "three entry points by existing habit" structure as the opening page of the workshop kit, so attendees self-route rather than all starting at the beginning.
- **Boundary, every module starts cold:** the dated-setup-details pattern (stable idea in the lesson, volatile steps on a dated page) suits C1 house rules; adapt it so any tool step in the kit carries a "checked on" date.
- **Layer framing vs ICM:** Jake's layers are a learner ladder; the repo's ICM layers are routing contracts. Keep them separate in training material to avoid confusing attendees.

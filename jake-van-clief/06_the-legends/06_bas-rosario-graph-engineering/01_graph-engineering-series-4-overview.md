# GRAPH ENGINEERING 📚 Series 4 Overview

*THE LEGENDS › 6. Bas Rosario - Graph Engineering · Author: Bas Rosario · Source: text lesson*

## Summary

Bas introduces rung five, the top of his ladder. A loop is one worker iterating; a graph is many workstreams running in parallel, with dependencies and designed convergence points. The learner stops designing a conversation and starts designing a topology: what runs beside what, what waits, where it all converges. He argues the skill is not new, since anyone who has coordinated a launch or a team has run a graph, and each branch is simply the earlier rungs stacked (room, memory, loop). What is new is the joints between branches.

## Core concepts

- **Topology:** the shape of the work, meaning parallel streams, waits and merge points.
- **Dependency chain of the ladder:** graphs need self-finishing loops, loops need memory, memory needs rooms, rooms need instructions. The order of the series is a prerequisite order.
- **Branches contain nothing new:** each is a worker with a room, memory and a loop; failure happens in the joints even when every branch is correct.
- **You already coordinate people this way:** the team mental model transfers one to one to parallel AI work, and the series makes each part precise.

## Frameworks and methods

The three classes preview the method: decomposition (cutting so pieces genuinely run beside each other, failing by being too coarse or secretly dependent), orchestration and handoffs (the contract between workers), and checkpoints and convergence (gates, merges, and reviewing outputs made without shared context). The pre-class exercise is to list work in flight and note what each piece waits on; pieces waiting on nothing could already run in parallel.

## Apply to icm-workshop

- **Mixed relevance and a boundary flag.** The goals say "never build an orchestrator". Bas's "orchestration" here means a human designing topology and contracts, which is compatible; it becomes a conflict only if it turns into a script or standing agent that drives branches and merges outputs. Treat the series as design vocabulary for Jamie, not as architecture to build.
- **Jamie's week as a graph:** the C3 desk (morning glance, Friday review) is the one place where parallel streams (clients, modules) land. The "draw your week and mark what each piece waits on" exercise is a good O4 workshop item and could feed the C3 Friday review design.
- **Shared core:** fact-before-fan-out matches C1 (one home per fact) at graph scale; see class 1.

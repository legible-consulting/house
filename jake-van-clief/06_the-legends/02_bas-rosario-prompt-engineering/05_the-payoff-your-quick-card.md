# The payoff: Your quick card

*THE LEGENDS › 2. Bas Rosario – Prompt Engineering · Author: Bas Rosario · Source: text lesson (quick card also attached as a PDF)*

## Summary

The payoff post joins the three classes into one method and then presents the series' quick card. Bas stresses that the learner never needed a formula, only a name for the task, a questioning order, and three failure checks. He also marks the limit of rung one: a well-shaped prompt gives a good answer while you steer live, but does not by itself deliver the same answer tomorrow or from a colleague. That repeatability is what the next rung, context, is for.

## Core concepts

- **The three classes in sequence:** name the ask, route it by asking strict types first, then diagnose failures in a set order.
- **Formula versus method:** a formula is someone else's frozen shape; the method is what lets you rebuild a shape for your own task.
- **The edge of rung one:** a prompt controls a single live interaction. Repeatability across days, people and bad model days is a different problem.
- **Card as working set:** the formulas you keep reaching for are bookmarked, not memorised, with the library holding the rest.

## What the quick card covers and how to use it

The card is a one-page reference built around five verbs: name it, route it, shape it, check it, iterate on purpose. It lists the eight task kinds with their giveaway questions, the routing order with the split-if-mixed rule, the requirement each type's prompt must carry, the three-layer failure check, and the one-change-per-run iteration habit. Use it by pasting your next real ask next to it, running the five steps aloud, and then saving the card with one prompt you actually used plus a one-line log of task, shape, check and result. It is a memory aid for the series, not a replacement for the three classes; the lesson page carries updated wording compared with the PDF.

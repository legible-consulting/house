# Resources 📚

*THE LEGENDS › Don Roy – Master Builder · Author: Don Roy · Source: text lesson*

## Summary

Don lists two community practice resources. One is a custom tutor, built as a repository that you open in Claude, which teaches the Foundations courses step by step and checks the learner's folder work. The other is a daily puzzle game where a shuffled workflow must be re-ordered so an agent can run it properly, with a leaderboard. A page addendum cautions that scores or tutor responses are only one signal and advises explaining and building something yourself.

## Tools, settings and resources

- **ICM Foundations Tutor** — repo-based teaching assistant for the Foundations material — https://github.com/donroy26/Clief-Notes-Foundations-Tutor — community-built, not by Jake.
- **ICMadness** — daily workflow-ordering puzzle on ICM fundamentals — https://donsbookshelf.com/icmadness/.

## Apply to icm-workshop

- **O4:** ICMadness-style "restore the order of a shuffled workflow" is a ready-made exercise idea for the workshop kit; check the tutor repo only as a model of a cold-start teaching folder, and never run third-party repo code without reading it first.

# Tools for your Toolchest

*David's Corner › Tools · Author: Roc Lee · Source: text lesson*

## Summary

Roc Lee's find, republished here, points to two visual-design helpers. One is a Chrome extension that extracts a website's visual style into a DESIGN.md file that an assistant can read; the other is a JavaScript animation library with an easing editor. The advice is to pick one design question (style or motion), capture a reference, apply one change to a small component, and compare against the intended outcome, keeping the decisions in project design notes.

## Core concepts

- **Extracted style as a starting reference:** review it, keep what fits, restate it for your own page rather than cloning.
- **Motion needs a purpose:** state change, attention guidance or sequence explanation; start with one element.
- **Compare curves on the same movement** and keep the one easiest to follow.

## Tools, settings and resources

- **DESIGN.md Style Extractor** — Chrome extension producing a style file for use with Claude — Chrome Web Store listing and the bergside/design-md-chrome repository. Not vetted here.
- **Anime.js** with its easing editor — animation library — animejs.com.

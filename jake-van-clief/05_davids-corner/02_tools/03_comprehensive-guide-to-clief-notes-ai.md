# Comprehensive Guide to Clief Notes AI

*David's Corner › Tools · Author: David's Corner (author not stated) · Source: text lesson*

## Summary

A guide to using the community's own assistant (the Clief Notes Agent) to locate relevant lessons and posts. It sends readers to the current setup page, advises registering with the same email as Skool and choosing the student route, and offers a prompt shape asking for a lesson title, a section and one checkable action, with an instruction to say so when material is missing. It then lists non-agent routes through the classroom and a troubleshooting note. Several original tables are retained for history; the page flags some as outdated (access limits, a Node.js prerequisite, a Claude-only setup) and defers to the live pages.

## Core concepts

- **Ask for a source, not an answer:** request the closest existing lesson, a section and one verifiable action.
- **Verify the routing:** open the suggested page and check it answers the question.
- **Live pages govern:** pricing, quotas and setup steps in the retained figures are unverified.
- **Safe support requests:** share error and device, not passwords or payment details.

## Claims and evidence

- A three-prompt free limit and paid prices appear in a retained image — page says unverified; do not rely on them.
- Node.js requirement for Claude Code — page corrects it as outdated.

# Stop automating your frustration. Audit it first.

*David's Corner › Learning for Everyone · Author: David's Corner (author not stated; credits Laura L.'s workflow-audit discussion) · Source: text lesson*

## Summary

A community skill that scores a workflow before anyone chooses to automate it. Impact (value of a right result) and risk (cost of a wrong one) are scored 1 to 5, with risk floored by four conditions: the output binds the business, reaches a customer, feeds another system, or damages trust if wrong. The score then picks an operating pattern: automate, hybrid or manual. A hybrid layout adds a review-gate folder, with the caveat that folders cannot enforce a halt; the executing system must check approval and stop the agent approving itself.

## Core concepts

- **Impact and risk scoring** with reasons recorded for each score.
- **Three operating patterns:** automate for low-consequence tested work, hybrid with human review of consequential output, manual with AI only assisting.
- **Gate enforcement:** a file proves nothing unless the runner blocks when approval is missing.
- **Test the block** before using real accounts.

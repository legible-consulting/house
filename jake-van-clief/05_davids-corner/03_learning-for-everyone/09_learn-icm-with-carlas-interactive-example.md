# Learn ICM With Carla's Interactive Example

*David's Corner › Learning for Everyone · Author: Carla Bosteder · Source: text lesson (links to an interactive Claude artifact)*

## Summary

A pointer to Carla Bosteder's interactive walkthrough in which a learner turns a messy process, following a character called Maya, into an ICM workflow one decision at a time. The page asks the learner to identify the desired output, write down inputs, stages and the review decision they chose, then rebuild that small structure as real folders. The check is whether another person can follow it from source to draft to reviewed output unaided. The example is hosted as a Claude artifact; if unavailable, fall back to the Foundation first-folder exercise.

## Core concepts

- **Output first, then inputs and stages.**
- **Review decision recorded** as part of the structure.
- **Cold-reader check:** a stranger should be able to follow the folder.

## Tools, settings and resources

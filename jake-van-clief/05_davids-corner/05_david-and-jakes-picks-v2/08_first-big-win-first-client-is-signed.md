## Summary

Richard's story of a conversation becoming a scoped opportunity before the product was finished. The page keeps the details in the original post and gives a discovery exercise: for a fictional call, write the repeated problem, the affected person, the current workaround, the smallest useful result and one unanswered question. The check is whether you can describe the result you would deliver while avoiding any commitment to a tool you have not yet proven. The story is an example, not a forecast of revenue.

## Core concepts

- **Problem before build.**
- **Smallest useful result** as the first offer.
- **No unvalidated promises.**

## Apply to icm-workshop

- **S2 client research:** the five discovery fields make a ready template for the prospect profile Jamie takes into a first call.
- **S3 proposal:** the smallest useful result lines up with a problem-approach-scope-timeline offer; and with the goals' note that only "straight to proposal" has landed work.

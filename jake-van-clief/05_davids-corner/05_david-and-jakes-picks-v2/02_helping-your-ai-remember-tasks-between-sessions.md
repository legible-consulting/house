# Helping your AI remember tasks between sessions

*David's Corner › David and Jake's Picks V2 · Author: Millenial Cat (member; post summarised by David's Corner) · Source: text lesson (links to original post)*

## Summary

A pointer to Millenial Cat's session-aware memory system (version 2.8 per the page), which tracks open tasks, recent activity and project threads across conversations. The lesson itself does not reproduce the system; it asks you to study how it decides what to save and retrieve, then try a miniature: save a task's goal, sources, last result, open question and next action in a progress file, start a fresh chat and supply the file explicitly. The review asks whether the assistant names the next action with evidence and without inventing completed work.

## Core concepts

- **Minimum state to resume:** goal, sources, last result, open question, next action.
- **Saved file versus automatic memory:** distinct mechanisms; neither guarantees recall.
- **Inspect what was actually read.**

## Apply to icm-workshop

- Adapt for C2 and C3: each client folder already carries "where it stands, what is next, who is waiting"; the five fields are a candidate shape for a per-client state file, with the Friday review reading them. One home per fact: state lives there only.
- Fits "every module starts cold": explicit supply beats automatic memory.

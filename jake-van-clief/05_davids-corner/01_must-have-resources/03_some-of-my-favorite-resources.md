# Some of my Favorite Resources

*David's Corner › Must Have Resources · Author: David · Source: text lesson*

## Summary

David's saved list of roughly seventeen creators and newsletters covering AI analysis, implementation tutorials, one-person business, offers and marketing, model reviews, and technical education. The page's real contribution is a consumption protocol: write the question first, then record where the item came from and when it was published, plus one idea worth using, one weakness, and an inexpensive test of it. It warns that subscriber counts and confident demos are not evidence you will get the same result.

## Core concepts

- **Question before content:** state what you want answered before opening a video.
- **Source note format:** source, date, one idea, one limitation, one check.
- **Primary-source rule:** for tool features or technical claims, follow through to the original docs or research.
- **Snapshot caveat:** schedules, topics and products drift.

## Tools, settings and resources

- Creator list including Nate B. Jones, Andrej Karpathy, Alex Hormozi, Matthew Berman, The Rundown AI and others — see the lesson for the full set. Undated beyond the page's own snapshot.

## Apply to icm-workshop

- Adopt the note format for O1: each tool or claim picked up from a creator becomes a dated entry with a limitation and a recheck date, ending in adopt, watch or decline.
- Reject importing the creator list itself; it is not tied to any goal.

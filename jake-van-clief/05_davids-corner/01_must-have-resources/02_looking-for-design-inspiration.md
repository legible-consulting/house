# Looking for design inspiration?

*David's Corner › Must Have Resources · Author: David · Source: text lesson*

## Summary

David's curated shelf of design reference sites, framed as input to a concrete brief rather than browsing for its own sake. The method: pick one page or component, save three references with source URLs, name one useful feature in each, then state what to adapt and what to leave out. The shelf spans general visual research, UI pattern libraries, graphic and brand sources, motion/3D, reusable files and showcases, and offline sources. The page says it is a curation snapshot, not a current ranking.

## Core concepts

- **Inspiration into a brief:** three references, one named feature each, an adapt/leave-out note.
- **Reuse caution:** check source terms before copying assets or code.
- **Verification:** test the resulting layout at narrow width; resemblance to a reference proves nothing about audience fit.
- **Tool-light:** a folder of screenshots and notes is enough.

## Tools, settings and resources

- **Mobbin, Refero, Pageflows** — UI and product pattern libraries.
- **Figma Community, Webflow and Framer showcases** — reusable files and examples.
- **getDesign** — contributed by Carl Gutierrez.

# 15 AI Accounts — David's Curation

*David's Corner › Must Have Resources · Author: David · Source: text lesson*

## Summary

A reading list of fifteen X accounts from AI researchers, educators and practitioners, refreshed on 26 September 2026 per the page. Each entry carries a one-line topic note so a reader can choose a starting point by question, such as deep learning explanations, applied ML education, prompt behaviour or research papers. The page frames it as a snapshot, not a ranking, and asks readers to follow a post through to its paper, docs or code and save one dated finding.

## Core concepts

- **Pick by question:** choose one or two accounts matching a current problem.
- **Follow to the source:** a post is a pointer; the paper, docs or code is the evidence.
- **Treat claims and demos as things to examine** before reuse.
- **Specific recommendations:** when sharing an account, cite a post and what it clarified.

# Prompt Patterns: Context and Review

*David's Corner › Developer Resources · Author: collection credited to @kyronis_talks on X (shared via David's Corner) · Source: text lesson*

## Summary

Two prompt patterns to test, plus an attached prompt collection. The first is a context brief: state the outcome, audience, source material, constraints, what has been tried and the remaining gap, and have the assistant identify missing information before producing the deliverable. The second asks for a reviewable answer: a recommendation with assumptions, sources and open questions, separating what the supplied material establishes from inference, plus a check to run before use. The page says an explanation is something to evaluate, not a transcript of hidden reasoning, and that performance claims should be tested.

## Core concepts

- **Context brief:** gap-first prompting reduces guessing.
- **Reviewable answer:** facts versus inference, with an explicit pre-use check.
- **Same-task comparison:** run your usual prompt and the pattern on identical notes, then score missing actions, invented details and editing effort.

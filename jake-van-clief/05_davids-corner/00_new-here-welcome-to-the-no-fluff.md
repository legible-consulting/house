# New Here? Welcome to the no fluff zone!

*David's Corner › Welcome · Author: David's Corner (author not stated) · Source: text lesson*

## Summary

A short orientation page for David's Corner, a reference shelf of practical posts from David, Jake and a handful of named community members. It tells a newcomer to pick one job (decode a term, find a visual reference, pick a learning source, improve project instructions), shows which sub-module holds what, and ends with a tiny exercise: read one page, record the source, the idea, and one checkable result. The stance is "use what works, you stay the author", and attribution travels with anything adapted.

## Core concepts

- **Shelf, not course:** the module is a set of independent references; nothing has to be read in order.
- **Job-first navigation:** each entry point is framed as a task, not a topic.
- **Attribution travels:** anything adapted should keep the original author's name.
- **Small verified result:** the exit condition is a recorded source plus one result you can check.

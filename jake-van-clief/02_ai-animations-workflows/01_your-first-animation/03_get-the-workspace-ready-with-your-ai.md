# 1.3 Get the Workspace Ready with Your AI

*AI Animations & Workflows › Module 1: Your First Animation · Author: Jake Van Clief · Source: Skool video · Length: ~3:30*

## Summary

Two ways to get a working animation workspace: download the prepared Premium Vault package, or have your own AI design a smaller version from an empty folder using the five stages. Either way, the AI inspects the machine, proposes a setup plan, and only then installs anything. The lesson ends with a separate example project holding a one-line fictional note and a reviewed brief stating audience, outcome and what the finished animation should help someone do.

## Core concepts

- **Plan before install:** the AI reads the workspace instructions, reports what is installed and missing, and shows the setup plan before running anything.
- **Route A, prepared package:** a dated zip with a start file, an agent instruction file, an animation command-line script, stage folders and a videos folder. Keep the structure intact because scene tools and examples depend on it. A tiny silent sample scene exists purely to test preview and export.
- **Route B, self-built:** the AI proposes, per stage, input, output file, tool and human check, separates reusable instructions from per-video folders, then writes the structure after agreement. Stages are implemented as the learner reaches them, not up front.
- **One project per video:** a fresh project is created beside the examples, never overwriting them. Paid voice configuration is deliberately deferred.
- **Brief before script:** the source is saved verbatim and a brief is reviewed first; the check is that action, owner and due day come out exactly as the source says with no invented date or extra work.

## Tools, settings and resources

- **Animation & Voice Workspace ZIP (Premium Vault)** — the prepared route; the dated filename is on the lesson page, dated late September 2026.
- **Python, a browser, FFmpeg** — dependencies of the prepared Windows workspace; a doctor script reports what is missing.
- **Foundation 1.3 and 1.4** — fallback help for opening a project and picking a setup.

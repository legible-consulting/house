# 1.1 Welcome and Your Route Through This Module

*AI Animations & Workflows › Module 1: Your First Animation · Author: Jake Van Clief · Source: Skool video · Length: ~1:30*

## Summary

A short orientation to Module 1. Jake frames the module as building one small narrated animation while giving the work a permanent home in a folder, so that when something looks or sounds wrong the learner knows which file to ask the AI to change. The running example is a one-line fictional meeting note that gets turned into an action card. Learners are told to watch 1.2 first, then pick a setup route in 1.3.

## Core concepts

- **The folder is the point:** the AI does most of the file work; the learner's value is knowing where each artefact lives so they can direct corrections precisely.
- **One shared example first, own idea later:** every lesson carries the same fictional note through script, voice, plan, scene and export; the learner's own idea waits until 1.8.
- **Two routes in:** a prepared Premium Vault workspace, or a workspace the learner has their own AI build from an empty folder. Plain chat works too, with the learner saving and running files themselves.
- **Human judgement stays:** the learner decides what the video should teach and whether the result actually explains it.

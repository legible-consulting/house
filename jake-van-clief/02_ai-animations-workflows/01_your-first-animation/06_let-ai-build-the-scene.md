# 1.6 Let AI Build the Scene

*AI Animations & Workflows › Module 1: Your First Animation · Author: Jake Van Clief · Source: Skool video · Length: ~2:45*

## Summary

The AI writes the animated scene from the reviewed brief, voice, timings and cues, captures stills at key beats, and opens a preview with the voice playing. The learner does not need to read code; they need to know which file controls what, so each correction request is aimed at the right place. The success test is whether a viewer can follow the explanation, not whether the animation is elaborate.

## Core concepts

- **Layout vs timing split:** one scene file controls drawing and layout; the cues file controls when beats start. Text hidden behind a character is a layout fix; a highlight that arrives early is a timing fix.
- **Corrections tied to a moment and a viewer need:** "keep the due day readable during this beat" beats vague feedback. Reopen the preview after each change and re-check that moment.
- **Review criteria:** the action, owner and due day stay accurate and visible on the busiest beat; one emphasis at a time; room for captions and any character; phone-size legibility.
- **Honest visuals:** a drawn card is fine for a fictional concept, but real captures should be used when teaching clicks in an actual app.
- **Style is swappable:** once the explanation works, a different visual style can be requested while keeping content and timing, which is what makes the workspace reusable.

## Frameworks and methods

1. Hand the AI all upstream artefacts and ask for the scene plus stills plus a voiced preview.
2. Ask it to show which file controls layout and which controls cue timing.
3. Review at the busiest beat, then smaller viewing size, then with voice.
4. Correct by moment and need; reopen preview.

## Tools, settings and resources

- **Scene file and cues file in the prepared workspace** — the two control points.
- **Stills command** — contact-sheet of beat frames used as a pencil-test check, which the AI inspects for overlap.

## Key moments

- [0:00] The AI builds from the plan; keep the note accurate.
- [1:02] Learn which file controls layout and which controls timing.
- [2:02] Try smaller sizes and later restyle without changing content.

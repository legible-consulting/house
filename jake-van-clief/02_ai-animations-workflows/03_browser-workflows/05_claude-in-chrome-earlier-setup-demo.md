## Summary

A short Anthropic product demo of Claude in Chrome, kept as a reference for the alternative browser tool. The demo shows an assistant gathering renovation budget details from a planning doc and contractor emails, updating a spreadsheet, and drafting an email to share with a partner, with the user approving the final send. Narration highlights granular permissions, prompt-injection protection, site restrictions and confirmation before sensitive actions. The page adds that current setup lives in the official guide and recommends starting with the same read-only check as 3.1.

## Core concepts

- **User stays in control:** actions are limited by permissions, and sensitive steps such as purchases or sending require approval.
- **Safety framing:** the demo claims protections against prompt injection and restricted sites; this is vendor marketing, unverified by the lesson.
- **Same module workflow either way:** audit, one-change test and saved-result checks work with either tool.

## Tools, settings and resources

- **Claude in Chrome extension** — use the same Chrome profile where it is installed; review the permissions guide; labels may differ from the recording.

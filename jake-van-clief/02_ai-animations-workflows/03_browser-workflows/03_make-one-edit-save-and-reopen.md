# 3.3 Make One Edit, Save, and Reopen

*AI Animations & Workflows › Module 3: Browser Workflows · Author: Jake Van Clief · Source: Skool video · Length: ~4:30*

## Summary

Apply the single reviewed replacement from the audit to one authorised page, then save and reopen it by URL to confirm what actually persisted. The request given to the assistant names the destination, the new material, a preservation boundary and a finish line. The lesson stresses that an editor preview or a successful save click is not evidence; the reopened page, links, media and publication state are.

## Core concepts

- **Task shape:** exact destination, supplied replacement, boundary (keep URL, discussion, resources, media, draft or published state) and a finish line (save, reopen, compare, report).
- **Stop on surprise:** when a control threatens to remove unrelated material, or the live page does not match the supplied source, the assistant halts and reports.
- **Check as the learner would:** read the surrounding paragraph, follow the changed link to its destination, play the video, download and open the resource, confirm publication state; an administrator view does not prove member access.
- **Unavailable actions:** the built-in browser's documentation says automated uploads are unavailable, though the demo host managed one; do that step by hand and give the page back for inspection, and never report an upload from the presence of a local file.
- **Small corrections:** name the first difference, make a small fix, save and reopen again, and say what remains unverified.
- **Record the routine:** a short workflow file holds starting URL, material to supply, allowed change, preservation list and final checks, plus the previous working version.

## Frameworks and methods

Pilot sequence: before record, small job, edit, save, reopen, compare, report, then write down the working routine and test it on the next named page.

## Tools, settings and resources

- **Codex** — Jake's current preferred browser agent; the sequence works with others or by hand.

## Claims and evidence

- A real classroom edit and a video upload were shown; the upload route is host-specific and the page says so.
- Some Save steps took seconds while research, writing, media preparation and verification took far longer, per the page.
